# UNIT — Unified Toolkit

UNIT เป็นโปรแกรมเดสก์ท็อปที่รวมเครื่องมือสำหรับวิเคราะห์ข้อมูลและไฟล์ในงาน Cybersecurity และ CTF (Capture The Flag) เขียนด้วย Python และ CustomTkinter ผู้ใช้สามารถแปลงข้อมูล ตรวจไฟล์ ต่อเครื่องมือหลายขั้นตอน และเรียกผู้ช่วย AI ผ่านหน้าต่างเดียว

เอกสารนี้อ้างอิงโค้ดในโปรเจกต์ที่ตรวจเมื่อวันที่ 14 กันยายน 2026 โดยแยกความสามารถที่มีแล้วออกจากเมนูที่ยังไม่ได้พัฒนา

## โปรแกรมทำอะไรได้บ้าง

- Encode / Decode ข้อความ เช่น Base64, Hex, URL และ ROT13 พร้อมโหมดเดารูปแบบข้อมูล
- คำนวณ Hash ของข้อความ และทำ Bitwise ด้วย XOR, OR, AND
- ตรวจชนิดไฟล์ ส่วนหัวไฟล์ ข้อมูล metadata และค้นหาข้อความหรือรูปแบบ flag
- จัดลำดับเครื่องมือ CLI เป็น Pipeline เพื่อส่งผลลัพธ์ระหว่างขั้นตอน
- สนทนากับ Gemini CLI เพื่อช่วยวิเคราะห์ข้อมูล และอนุมัติคำสั่งหรือการบันทึกไฟล์ที่ AI เสนอ
- เปิดโปรแกรมภายนอกผ่าน App Portal และเพิ่มรายการเครื่องมือของผู้ใช้
- ดูประวัติกิจกรรม สถิติการใช้เครื่องมือ ไฟล์ล่าสุด และจัดรายการโปรดตามหมวดหรือการแข่งขัน

| --- | --- | --- | --- |

| Data Hashing | แปลงข้อความ คำนวณ Hash และทำ Bitwise | ถอด Base64 หรือ XOR ข้อมูลด้วย key | มีหน้าการทำงาน |
| File Inspection | ตรวจคุณสมบัติและค้นหาข้อมูลในไฟล์ | ตรวจ header, ดึง strings, กรองด้วย regex | มีหน้าการทำงาน |
| Pipeline | ต่อเครื่องมือหลายขั้นตอน | ถอดข้อมูลแล้วส่งผลลัพธ์ไปตรวจชนิดไฟล์ | มีหน้าการทำงาน |
| Gemini CLI | ใช้ AI ช่วยวิเคราะห์ผ่าน Gemini CLI | อธิบายผลลัพธ์และเสนอคำสั่งวิเคราะห์ต่อ | ต้องติดตั้งและเชื่อมต่อ CLI |
| App Portal | รวมปุ่มเปิดโปรแกรมภายนอก | เปิด Wireshark, Ghidra หรือ Terminal | ต้องติดตั้งโปรแกรมปลายทาง |
| My Tools | จัดกลุ่มทางลัดเครื่องมือส่วนตัว | สร้างกลุ่ม ค้นหา และกดแต่ละชิปเพื่อเปิดโหมดย่อย | มีหน้าการทำงาน |
| Challenge | ติดตามจำนวนข้อที่แก้และเวลาทำ CTF | เพิ่มการแข่งขัน แก้คะแนน และเริ่ม/พักเวลา | มีหน้าการทำงาน |

### Dashboard — ภาพรวมและทางลัด

แสดงสถิติจากกิจกรรมที่หน้าต่าง ๆ บันทึก เช่น การใช้เครื่องมือ ผลการทำงาน และ flag ที่ตรวจพบ มีรายการเครื่องมือที่ใช้บ่อย ไฟล์ล่าสุด และรายการโปรด ผู้ใช้เพิ่มหมวด จัดรายการโปรด ตั้งคีย์ลัด และเลือกการแข่งขันเพื่อแยกบริบทของกิจกรรมได้

ข้อมูลถูกเก็บที่ `data/dashboard_state.json` ภายในโปรเจกต์ โดยเก็บเหตุการณ์ล่าสุดได้สูงสุด 2,000 รายการ สถิติเหล่านี้เป็นข้อมูลที่แอปบันทึก ไม่ใช่คะแนนที่ยืนยันจากแพลตฟอร์มแข่งขัน CTF

### Data Hashing — แปลงและประมวลผลข้อมูล

มี 4 โหมดหลัก:

| โหมด | ใช้ทำอะไร | ตัวอย่างที่มีใน UI |
| --- | --- | --- |
| Encode | แปลงข้อความเป็นรูปแบบอื่น | Base64/32/45/58/62/85/16, Hex, Binary, Octal, Decimal, URL, HTML Entity, Unicode Escape, Reverse, ROT13 |
| Decode | ถอดรูปแบบข้อมูลกลับ พร้อม Auto Detect | Base64, Hex, Ascii85, URL Decode และรูปแบบอื่นตามรายการในหน้า |
| Hash | สร้างค่า digest จากข้อความ | MD5, SHA-1, SHA-2, SHA-3, BLAKE2 |
| Bitwise | ประมวลผลระดับบิตด้วย key | XOR Mask, XOR Unmask, OR Mask, AND Mask |

รองรับการเปิดไฟล์เข้าช่องข้อมูล ค้นหาและไฮไลต์ผลลัพธ์ รวมทั้งอ่านข้อความ byte array หลายรูปแบบในโหมด Bitwise และตรวจ key ที่ฝังอยู่ใน snippet บางรูปแบบ เช่น `$key = 0x4A`

Hash ในหน้านี้คำนวณจากข้อความที่ส่งเข้า `hash_data()` ไม่ใช่ฟังก์ชันตรวจ checksum ของไฟล์ไบนารีโดยตรง และ Hash ไม่ใช่การเข้ารหัสที่ถอดกลับได้ ส่วน Auto Detect เป็นการเดารูปแบบ ไม่รับประกันว่าจะได้คำตอบถูกต้องทุกข้อมูล

### File Inspection — ตรวจไฟล์และค้นหาข้อมูล

เลือกไฟล์หรือใช้ Drag & Drop ได้หลายไฟล์ พร้อมสลับดูผลลัพธ์ของแต่ละไฟล์ แสดงข้อมูลไฟล์และ MD5 มีเครื่องมือ Header Check, Executable Check, Strings, `file`, `zsteg` และ Exiftool

ค้นหาข้อความ กรองผลด้วย regex ที่มีให้หรือเพิ่มเอง และส่งข้อความที่เลือกไปยัง Data Hashing หรือ Gemini CLI ได้ เครื่องมือ `file`, `zsteg` และ `exiftool` ต้องติดตั้งแยกในระบบ

### Pipeline — ทำงานหลายขั้นตอนต่อกัน

เพิ่มเครื่องมือเป็น node บน canvas ลากเพื่อจัดลำดับ แล้วรันตามลำดับที่กำหนด แต่ละขั้นมีหน้าต่างให้ดู input ปรับ options และดูคำสั่งก่อนรัน สามารถใช้ผลจากขั้นก่อนหน้า เลือกไฟล์ใหม่ หรือกลับไปใช้ไฟล์ต้นฉบับได้

รองรับผลลัพธ์แบบ bytes และสร้างไฟล์ชั่วคราวสำหรับส่งต่อไปยังเครื่องมือที่รับไฟล์ มีการบันทึกผลลัพธ์ เพิ่ม custom tool สร้าง Pipeline ผ่าน wizard และโหลด Pipeline ที่บันทึกไว้กลับมาใช้

หมวดเครื่องมือที่กำหนดไว้ใน `Pipeline/custom_tools.json`:

| หมวด | ใช้ทำอะไร | ตัวอย่างเครื่องมือ |
| --- | --- | --- |
| File Analysis | ดูข้อมูลดิบและเลขฐานสิบหกของไฟล์ | xxd, hexdump |
| Archive Extraction | แตกไฟล์บีบอัดหรือ archive | 7zip_extract, unzip, tar_extract |
| Steganography | ตรวจหรือดึงข้อมูลที่ซ่อนในไฟล์ | zsteg, zbarimg, steghide, binwalk_extract |
| Forensics | ตรวจ metadata แยกข้อมูล และวิเคราะห์หลักฐานดิจิทัล | binwalk, foremost, exiftool, tshark, dd |
| Cryptography | ถอดรูปแบบข้อมูล แปลงข้อความ หรือเรียกเครื่องมือเข้ารหัส | base64_decode, hex_decode, openssl enc |
| Pwnable | ตรวจชนิดไฟล์ คุณสมบัติ executable และ checksum | checksec, file, md5sum |
| Mobile Security | แยกและอ่านข้อมูลแอป Android | apktool, jadx, dex_strings |
| Programming | ค้นหา ตัด เรียง และกรองข้อความ | grep, cut, sort, uniq, awk |
| Reverse Engineering | อ่าน strings และข้อมูล assembly ของไบนารี | strings, objdump |
| Network | เรียกเครื่องมือวิเคราะห์แพ็กเก็ตเครือข่าย | tcpdump |

รายการเหล่านี้เป็นนิยามคำสั่งสำหรับเรียกโปรแกรมภายนอก การมีชื่อในรายการไม่ได้หมายความว่าเครื่องนั้นติดตั้งเครื่องมือแล้ว

### Gemini CLI — ผู้ช่วย AI

เชื่อมต่อคำสั่ง `gemini` ที่ติดตั้งในเครื่อง เลือกโมเดล สนทนาพร้อมประวัติ และแนบเนื้อหาไฟล์ข้อความจาก path ที่ตรวจพบในข้อความได้ การทำงานต้องอาศัยการยืนยันตัวตนและการเข้าถึงบริการ Gemini

เมื่อคำตอบมี `[EXEC]...[/EXEC]` แอปแสดงหน้าต่าง ALLOW / DENY ก่อนรัน shell command และส่งผลกลับให้ AI วิเคราะห์ต่อ สูงสุด 2 รอบต่อข้อความ ส่วน `[SAVE:path]...[/SAVE]` จะขออนุญาตก่อนเขียนไฟล์ ซึ่งอาจเขียนทับไฟล์เดิม การยืนยันนี้อยู่ในขั้นตอนจัดการ tag ของแอป

### App Portal — เปิดเครื่องมือภายนอก

มีรายการเริ่มต้น เช่น Wireshark, Burp Suite, Ghidra, Nmap, Metasploit, Hashcat, CyberChef และ Terminal พร้อมค้นหาและตรวจการมีอยู่ของคำสั่ง ผู้ใช้เพิ่ม แก้ไข หรือลบ custom tool และเลือกแอปจากรายการของระบบได้

หน้านี้เป็นตัวเปิดโปรแกรม ความสามารถวิเคราะห์จริงเป็นของเครื่องมือปลายทาง หลายคำสั่งเริ่มต้นใช้ `x-terminal-emulator` และ `bash` จึงต้องปรับตามระบบปฏิบัติการที่ใช้งาน

## เริ่มใช้งาน

ต้องมี Python พร้อม Tkinter และสภาพแวดล้อมเดสก์ท็อปสำหรับแสดง GUI จากโฟลเดอร์โปรเจกต์ให้รัน:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r Requirements.txt
python app.py
```

บน Windows ให้ใช้ `.venv\Scripts\activate` แทนคำสั่ง `source` ชื่อไฟล์ dependency ใน repository คือ `Requirements.txt` โดยขึ้นต้นด้วย R ตัวใหญ่ บางระบบ Linux ต้องติดตั้ง Tkinter จาก package manager ของระบบเพิ่มเติม

Python dependencies หลักคือ `customtkinter`, `tkinterdnd2` และ `puremagic` ส่วนเครื่องมือ CLI ให้ติดตั้งแยกตามหมวดที่ต้องการใช้และตรวจว่าอยู่ใน `PATH` สำหรับ Gemini ต้องมีคำสั่ง `gemini` และตั้งค่าการยืนยันตัวตนให้เรียบร้อยก่อนเชื่อมต่อในแอป

## ตัวอย่างลำดับการใช้งาน

1. เปิด File Inspection แล้วเลือกไฟล์โจทย์เพื่อตรวจชนิดไฟล์และค้นหา strings
2. เลือกข้อความที่น่าสนใจส่งไป Data Hashing เพื่อถอดรูปแบบข้อมูล
3. หากต้องใช้หลายเครื่องมือต่อกัน ให้สร้างลำดับใน Pipeline และบันทึกไว้ใช้ซ้ำ
4. ส่งผลลัพธ์ไป Gemini CLI เมื่อต้องการคำอธิบายหรือแนวทางวิเคราะห์ต่อ
5. กลับ Dashboard เพื่อดูประวัติและปักหมุดเครื่องมือที่ใช้บ่อย

## My Tools และ Challenge

My Tools: กด New group ตั้งชื่อและเลือกเครื่องมืออย่างน้อยหนึ่งตัว แต่ละชิปเปิดหน้าพร้อมโหมดย่อยแยกกัน เช่น Base64, ROT, Hex, XOR หรือ zsteg ชิป App Portal กรองชื่อโปรแกรมให้ แล้วผู้ใช้กด Launch เอง ค้นชื่อกลุ่ม แก้ไข และยืนยันก่อนลบได้ ข้อมูลอยู่ที่ `config/my_tools_groups.json`

Challenge: กรอกชื่อและจำนวนข้อที่มากกว่า 0 แล้ว Create Challenge คลิกแถวหรือปุ่มแก้ไขเพื่อใส่จำนวนข้อที่แก้ได้ (0 ถึงจำนวนข้อทั้งหมด) และกด Start/Pause เวลาอัปเดตทุกวินาที การเริ่ม/พักบันทึกทันที ส่วนคะแนนบันทึกเมื่อกด Save ทุก timer เริ่มแบบพักและถูกพักพร้อมบันทึกเมื่อปิด UNIT ตามปกติ ข้อมูลอยู่ที่ `config/challenges.json` หากโปรแกรมถูก kill ขณะ timer ทำงาน การเปิดครั้งถัดไปจะคิดเวลาจาก timestamp ล่าสุดด้วย

สองหน้านี้ใช้พื้นหลังโทนเข้มเหมือน Dashboard รวมถึงช่องกรอกและ dialog โดยไม่เปลี่ยนตาม appearance mode ของแอป ไฟล์ config สร้างอัตโนมัติเมื่อบันทึกครั้งแรก หากอ่าน config ไม่ได้จะแจ้งข้อผิดพลาดและไม่เขียนทับไฟล์เดิม
